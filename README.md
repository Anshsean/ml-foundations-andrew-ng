# Machine Learning Foundations – Andrew Ng

This repository contains my implementations, experiments, and mini-projects while completing **Andrew Ng’s Machine Learning Specialization**.

The goal of this repo is to:

* Build strong ML fundamentals
* Implement algorithms from scratch
* Document learning, mistakes, and improvements

---

## Structure

* `week-1-linear-regression/` – Linear regression, cost functions, gradient descent
* `week-2-logistic-regression/` – Classification, sigmoid, decision boundaries
* `week-3-regularization/` – Bias–variance tradeoff, L2 regularization
* `week-4-neural-networks/` – Intro to neural networks (from scratch)

---

## Tools Used

* Python
* NumPy
* Matplotlib
* Jupyter Notebook

---

## Notes

* Most algorithms are implemented **from scratch**
* Libraries like `sklearn` are used only for comparison/validation
* Each folder contains a short README explaining what was done and learned
